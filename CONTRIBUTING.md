# Contributing

Thanks for taking the time to contribute! This repository is intentionally opinionated, so most changes are expected to be authored by me. If you want to suggest something, feel free to open an issue or a discussion first.

## Development

This repository is documentation and configuration focused, so there is no build step required. Update the Markdown or configuration files directly.

No specific tooling is required; please keep formatting consistent with the existing Markdown style.

## Pull Requests

- Use conventional commits (e.g., `feat: add new skill`).
- Keep PRs focused and include a clear description.
- Ensure CI passes before requesting review.
